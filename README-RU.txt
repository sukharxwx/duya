САЙТ ДЛЯ ОТКРЫТИЯ НА IPHONE

Это уже собранная статическая версия сайта. Исходники для повторной сборки (например, package.json и папка src) в исходном архиве не обнаружены.

САМЫЙ ПРОСТОЙ СПОСОБ ПОЛУЧИТЬ ССЫЛКУ:
1. На компьютере откройте https://app.netlify.com/drop
2. Распакуйте архив site_iphone_ready.zip.
3. Перетащите папку с файлами сайта (папку, где лежит index.html) на страницу Netlify Drop.
4. Дождитесь публикации — Netlify выдаст публичную ссылку вида https://....netlify.app
5. Откройте эту ссылку на iPhone в Safari.
6. Чтобы добавить на экран «Домой»: нажмите «Поделиться» → «На экран Домой» → «Добавить».

Важно: это статическая сборка. Серверная логика, если она требовалась исходному проекту, сюда не входит.
